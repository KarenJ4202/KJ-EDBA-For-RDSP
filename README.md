The Enhanced Discrete Bees Algorithm (EDBA) is proposed in 2018 [1].
This is a python version of EDBA.
Robotic disassembly sequence planning (RDSP) is applied.
Two models, a 9-part gear motor and a electric vehicle battery (EVB) are used in this RDSP problem. 

[1] J. Liu, Z. Zhou, D. T. Pham, W. Xu, C. Ji, and Q. Liu, ‘Robotic disassembly sequence planning using enhanced discrete bees algorithm in remanufacturing’, International Journal of Production Research, vol. 56, no. 9, pp. 3134–3151, May 2018, doi: 10.1080/00207543.2017.1412527.
